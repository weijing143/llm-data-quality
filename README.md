# 数据质量 × 大模型 · 研究阅读项目

围绕「数据质量对大模型的价值」这一主题整理的三份互相衔接的单页报告。所有页面均为**单文件静态 HTML、无外部请求**，可离线直接打开，也可部署到 GitHub Pages。

> 数据截至 2026-09-16。市场预测类数据口径各异，仅供参考，不构成投资建议。

## 在线阅读

部署 GitHub Pages 后，入口为 `index.html`。

## 目录

| 文件 | 定位 | 内容 |
| --- | --- | --- |
| `index.html` | 门户 | 项目导航与推荐阅读顺序 |
| `数据质量优化对大模型价值.html` | 框架篇 | 机制（为什么数据更好 ≈ 算力更多）→ 质量的四层定义 → 九个工程工位 → 案例 → 投入产出三本账 → 边界与争议 → 落地清单 → 术语表 |
| `数据质量研究动态-2025-2026.html` | 动态篇 | DeepSeek 与国内外实验室近 12–18 个月的数据侧论文 / 技术报告 / 官方消息，按时间倒序，区分一手 / 二手 / 传闻，可按实验室与主题筛选 |
| `数据质量近6个月汇总-2026-09.html` | 汇总篇 | 2026.03–09 的代表论文（含 "A Bitter Lesson for Data Filtering" 等争议性工作）、中国高质量数据集政策时间线、训练数据产业市场数字 |

## 推荐阅读顺序

1. **框架篇** — 建立「质量 = 单位 token 的有效梯度」的心智模型
2. **动态篇** — 把框架对照各实验室的真实做法
3. **汇总篇** — 看最新论文争议、政策与产业走向

## 本地查看

直接双击任意 `.html` 文件即可；或启动一个本地服务：

```bash
cd llm-data-quality
python -m http.server 8000
# 打开 http://localhost:8000
```

## 部署 GitHub Pages

仓库 Settings → Pages → Source 选 `main` 分支根目录，保存后访问
`https://<你的用户名>.github.io/<仓库名>/`。

## 来源说明

各报告页脚含完整的出处与核验说明（论文 arXiv 编号、政策文号、市场报告口径），
并区分一手来源、二手转述与传闻。
