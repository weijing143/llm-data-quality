S0

建立词汇表

约 2 小时 · 材料：框架篇「术语速查」+「先给结论」

目标：能用一句话向同事解释：为什么说"质量 = 单位 token 的有效梯度"； 分清预训练 / 持续预训练 / 后训练对数据的不同要求。

READING · 阅读
  • 框架篇 · 术语速查：十个词看懂数据质量讨论
  • 框架篇 · 先给结论：六句话讲完
  • 框架篇 · 定义：质量的四层与五维
SELF-CHECK · 自测
  • 去重、过滤、配比分别解决什么问题？哪个决定"模型见过什么"，哪个决定"模型多看什么"？
  • 为什么 SFT 阶段一万条精选样本可能比一百万条普通样本更好？
OUTPUT · 产出物
  • 用自己的话写一段 200 字的"数据质量是什么"，要求不使用"干净""脏"这类比喻。
S1

吃透机制与工程

约 6–8 小时 · 材料：框架篇主线 + 分析页图表

目标：理解"数据更好 ≈ 算力更多"的机制链条； 能把一条数据流水线拆成可验收的工位；知道每个环节失败的后果。

READING · 阅读
  • 框架篇 · 机制：为什么"数据更好"能等价于"算力更多"
  • 框架篇 · 工程：九个可验收的工位
  • 框架篇 · 案例：数据质量兑现成了什么（LIMA、FineWeb-Edu、Phi 等）
  • 分析页 · 图 1–4：看 65 条动态里各主题的真实分布
SELF-CHECK · 自测
  • FineWeb-Edu 用 38B token 达到对照 300B token 的水平——如果过滤掉的不是"坏数据"而是"难数据"，这个结论还成立吗？
  • 基准去污（decontamination）缺失时，模型报告里的哪个数字最先失真？
OUTPUT · 产出物
  • 画出一条八阶段数据流水线图，标注每阶段的工具与大致留存率（对照汇总篇 §3.2 核对）。
S2

追踪前沿与争论

约 6 小时 · 材料：动态篇 + 数据集 + 汇总篇论文区

目标：了解各家实验室在数据上的真实路线差异； 能陈述至少两个"文献并不一致"的开放争论及其双方证据。

READING · 阅读
  • 动态篇 · DeepSeek：数据侧做了什么（工业界最完整披露样本）
  • 动态篇 · 实验室画像 与 方法论趋势
  • 动态篇 · 仍未解决的争论 + 框架篇 · 争议清单
  • 汇总篇 · 近六个月代表论文：重点读 A Bitter Lesson for Data Filtering 与 LIMO/LIMR 两组相反方向的工作
  • 动手：下载 research-feed.csv，按 lab 或 topic 自己筛选一遍，复现分析页的某个结论
SELF-CHECK · 自测
  • "过滤价值随算力衰减"（Bitter Lesson for Data Filtering）和"好数据是最便宜的性能提升"矛盾吗？各自的前提是什么？
  • DeepSeek V4 为什么专门过滤"批量生成与模板化网页"？这和模型坍缩（model collapse）是什么关系？
OUTPUT · 产出物
  • 选一个开放争论（如合成数据配比上限），写一页 A4 的立场笔记：双方证据、你的判断、什么新证据会让你改变判断。
S3

看懂产业与政策

约 3 小时 · 材料：汇总篇政策与产业部分

目标：理解数据质量为何同时是技术问题、商业问题与国家战略； 能向非技术管理者讲清投入产出。

READING · 阅读
  • 汇总篇 · 政策与产业动态：国家数据局时间线 + 市场数字
  • 框架篇 · 投入产出：三本账与一个决策树
  • 汇总篇 · 趋势研判：给三类读者的启示
SELF-CHECK · 自测
  • 数据服务商的商业模式从"卖劳力"转向"卖资产"，这个转变对毛利率意味着什么？
  • 为什么欧盟 AI 法案第 10 条会把数据质量从最佳实践变成强制要求？
OUTPUT · 产出物
  • 以"是否值得自建高质量数据集"为题，套用三本账框架给你的团队写一份半页决策建议。
